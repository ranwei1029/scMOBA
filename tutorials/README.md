# M1 inference tutorials

- [Original scMOBA](scmoba_inference.ipynb): broad cell class prediction
  with the original Llama-based model. Use the original inference environment
  and original-tokenized M1 data.
- [scMOBA-Chat](scmoba_chat_inference.ipynb): single-cell RNA preprocessing
  from an M1 h5ad, Subclass prediction and gene/pathway follow-up questions.
  Install the [local deployment package](../scmoba-chat/README.md) separately.

Use a locally authorized M1 input. Real expression and evaluation artifacts
are not included. Notebooks contain no populated outputs. These are inference
examples, not full benchmark reproduction.
